Privacy Policy — Stamp News

Last updated: October 14, 2026

Stamp News ("the Extension") is a Chrome browser extension that lets users save ("stamp") news pages they visit, along with an automatically generated summary, tags, and an optional personal prediction. This page explains what data the Extension accesses, how it is used, and how it is stored.

1. What data the Extension accesses

When you open the Extension's popup on a web page, it reads the following information from the currently active tab only, and only while the popup is open:

  • The page title, URL, and hostname
  • The page's og:description / meta description, if present
  • A short excerpt of the visible page text (used to generate tags and a summary)
  • The page's og:image, if present
  • A screenshot of the currently visible tab, taken only if you press "Stamp this page"

The Extension does not access your browsing history as a list of past visits; it only reads the single page you are currently viewing, and only when you actively open the Extension's popup on that page.

2. How this data is used

The information above is used exclusively to:

  • Show you a preview of the current page inside the popup
  • Generate a short summary, sentiment label, category, tags, key actors, and possible prediction suggestions for that page
  • Create a "stamp" (a saved record) if and only if you click "Stamp this page"

3. Where this data is stored

All stamps you create are stored locally on your own device, using Chrome's storage.local API. This data is never transmitted to any server operated by the developer of this Extension. Uninstalling the Extension or clearing your browser's extension storage permanently deletes this data.

4. AI analysis

The Extension generates an AI-based analysis (summary, sentiment, impact, key actors, prediction ideas) of the page you are viewing. This works in one of two ways:

a) Free AI analysis through the Stamp News server (default)

  • The page title, site name, description and a short excerpt of the page text (at most 2,000 characters) are sent to the Stamp News server (stamp-news-api.stampnews520.workers.dev, hosted on Cloudflare Workers), which forwards them to Anthropic's API (api.anthropic.com) to generate the analysis and returns the result to your browser.
  • To apply the monthly free-analysis limit, the Extension creates a random installation identifier on your device. The server stores only a counter linked to this identifier and the month (deleted automatically after about 40 days), plus a daily total.
  • The Stamp News server does not save the page content, the analysis, your stamps or any account information in its database. The page data is used only to produce the analysis you requested.
  • Anthropic's handling of this data is governed by Anthropic's own privacy policy and terms. As the hosting provider, Cloudflare may keep short-lived technical request logs (such as IP address and time of request) for operating and securing the service.

b) Your own Anthropic API key (optional)

If you enter your own Anthropic API key in the Extension's Settings panel, the Stamp News server is not used. Your key is stored only on your own device (Chrome storage.local), is never sent to the developer, and can be removed at any time. The page title, description and a short excerpt of the page text are then sent directly from your browser to api.anthropic.com, billed to your own Anthropic account.

If the AI analysis is unavailable (for example, the monthly free limit is reached or there is no connection), the Extension falls back to a basic, fully offline keyword-based analysis that runs only in your browser.

5. Data sharing

The developer of this Extension does not sell, rent, or share any user data with third parties, other than sending page content to Anthropic (through Cloudflare) solely to generate the AI analysis described above. No analytics or tracking scripts are included in the Extension.

6. Permissions used and why

  • storage — to save your stamps, your optional API key and the random installation identifier locally on your device.
  • contextMenus — to add an "Open My stamps" item to the right-click menu of the toolbar icon.
  • tabs / activeTab — to read the title, URL, and content of the tab you are currently viewing when you open the popup.
  • host_permissions (<all_urls>) — so the Extension's content script can extract page metadata (title, description, image) on any news site you choose to stamp, without needing to be re-approved for every new site.

7. Children's privacy

This Extension is not directed at children and does not knowingly collect data from children.
